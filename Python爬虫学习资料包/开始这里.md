你好，这份资料来自一位朋友的分享。

包里有两套课程，**不是二选一，而是配合使用**：一套是 2-4 周能跑起来的实战入门，一套是 7 个阶段、65 个模块的系统课程。下面告诉你该怎么开始。

## 第一步：先搞清楚这两套是什么关系

```
02_零基础入门实战       ← 先看这个，2-4 周，能做出东西
01_系统性学习_65模块     ← 再啃这个，按阶段推进，打地基
```

## 第三步：装环境

### 入门课程（02）

只要三个库，其余全是 Python 标准库：

```bash
pip install requests beautifulsoup4 lxml
```

第 7 节讲动态页面（可选，约 150 MB）：

```bash
pip install playwright && playwright install chromium
```

### 系统课程（01）

**阶段 0-4 几乎全是标准库，开箱即跑。** 先跑这些建立感觉：

```bash
cd 01_系统性学习_65模块/code/stage2_core
python3 21_books_spider_project.py
```

阶段 5-6 才需要额外依赖：

```bash
pip install sqlalchemy duckdb polars apscheduler redis plotly pandas
```

> ⚠️ 如果报 `externally-managed-environment`，那是新版 Python 的 PEP 668 保护。
> 用虚拟环境最干净：
> ```bash
> python3 -m venv .venv && source .venv/bin/activate
> ```
> 容器/沙箱里图省事也可以加 `--break-system-packages`。

## 课程里最有价值的部分，不是"怎么写"

系统课程里所有数字都是真实跑出来的，而不是从文档里抄的。举几个例子，你跑一遍就知道含金量：

| 结论 | 课程里的实测 |
|---|---|
| SQL 注入的真实破坏力 | 字符串拼接返回**全表 6 条** vs 参数化返回 **0 条** |
| 批量提交 vs 逐条提交 | 快 **9 倍** |
| 向量化 vs for 循环写 Pandas | 快 **3,160 倍** |
| 并发超过拐点会怎样 | 吞吐**降 67%**，P95 延迟**涨 1200%** |
| 重试不加抖动的惊群效应 | 瞬时峰值 100 → 加抖动后 **5**（改善 95%） |

更重要的是，**每个坑都保留了完整的排查过程**（❌ 错误做法 → 现象 → 根因 → ✅ 正确做法）。比如：

- NFKC 规范化会把 `￥` 折叠成 `¥`，导致人民币被识别成日元
- `rowcount` 对「什么都没改」的 UPDATE 依然报告 1
- 脏数据率算出 133%，根因是一个字段被两条路径重复计数

这些光读文档学不到，必须真的踩一次。

## ⚠️ 一句必须说的话

这门课涉及反爬对抗、JS 逆向、验证码、代理池 —— 这些技术是**双刃剑**。

**只用于**：自有系统安全测试、有书面授权的渗透测试、公开教学靶场、公开数据的合规研究。

**绝对不要**拿去突破一个明确不欢迎自动化的商业网站。系统课程的第 **4.10 课**（`code/stage4_reverse/49_compliance.py`）列了真实判例与刑期，建议**在学阶段 4 之前**先读它。

技术让你能做到，但判断「该不该做」是你自己的责任。

## 建议的学习节奏

**第一周**：只做一件事 —— 打开 `02` 的 `index.html`，把 `code/` 里 6 个脚本**亲手敲一遍**（别复制粘贴），跑通，看到数据落到 CSV 里。

**之后**：打开 `01` 的 `课程总目录.html`，从阶段 0 开始，按「先跑一遍 → 再读代码 → 改参数重跑」三步走。

**第三步最重要。** 这门课所有结论都来自「改了什么 → 结果怎么变」的对照。改一次并发数、把阈值调小，看输出怎么变 —— 比读十遍结论有用。
